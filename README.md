# Dividir Conta

Aplicação web para organizar despesas compartilhadas em eventos, inspirada no fluxo de aplicativos como Splitwise.

## Recursos implementados

- Criar um evento e nomeá-lo.
- Adicionar e remover participantes.
- Registrar despesas com descrição, valor, data e pagador.
- Divisão igual entre qualquer quantidade de participantes.
- Divisão personalizada por valor.
- Arredondamento correto em centavos na divisão igual.
- Saldo líquido de cada participante.
- Cálculo automático de quem deve pagar quem para quitar o evento.
- Exclusão de despesas.
- Interface responsiva para celular.
- Dados persistidos localmente no navegador.

## Próximas evoluções

Convites/compartilhamento, múltiplos eventos, autenticação, sincronização em banco de dados, despesas recorrentes, anexos de comprovantes e registro de pagamentos realizados.
